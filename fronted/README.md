# 前端 README

本目录是项目的前端模块，提供一个本地运行的人脸识别控制台。页面使用原生 HTML、CSS 和 JavaScript 编写，不依赖打包工具，直接通过浏览器打开 `index.html` 即可使用。

前端主要负责图片选择、批量上传、识别结果展示、身份库切换、评测结果查看和错误样例预览；实际的人脸检测、识别和评测计算由后端 API 完成。

## 目录说明

```text
fronted/
  index.html      页面结构
  styles.css      页面样式
  app.js          前端交互和 API 调用逻辑
  BACKEND_API.md  后端接口说明
  DESIGN.md       前端设计说明
```

## 功能

- 检查后端连接状态。
- 在“自采集 20 人”和“CelebA 100”两个身份库之间切换。
- 支持单张、多张图片上传。
- 支持从文件夹批量导入图片。
- 支持纵向列表视图和横向轮播视图查看识别结果。
- 支持点击识别结果图片进行放大预览。
- 支持运行数据集评测并展示准确率。
- 支持查看评测错误样例。
- 支持在后端重建身份库后重新加载缓存。

## 使用方式

1. 先在项目根目录安装并启动后端：

```powershell
pip install -r requirements.txt
python -m backend.cli api --host 127.0.0.1 --port 8000
```

2. 确保身份库已经构建：

```powershell
python -m backend.cli build self
python -m backend.cli build celeba
```

3. 用浏览器打开：

```text
fronted/index.html
```

页面会自动请求后端的 `/health` 接口。如果右上角显示“后端已连接”，即可上传图片进行识别。

## 后端地址

前端默认后端地址写在 `app.js`：

```js
const API_BASE = 'http://127.0.0.1:8000';
```

如果后端端口或主机发生变化，需要同步修改该值。

## 页面模块

识别页：

- 选择身份库。
- 上传或拖拽图片。
- 批量识别所选图片。
- 展示每张图片的检测框、身份编号、姓名、相似度和结果图。

评测页：

- 选择身份库。
- 加载测试图片列表。
- 运行后端评测接口。
- 展示按人脸和按图片统计的准确率。
- 展示错误样例并支持预览。

## 注意事项

- 前端本身不做人脸识别，必须先启动后端 API。
- 如果身份库文件不存在，对应选项会显示为缺失并被禁用。
- 如果重新运行 `build self` 或 `build celeba`，需要点击“重新加载身份库”按钮或重启后端。
- 项目文件夹名为 `fronted`，含义是前端目录。
